# Constitucion del proyecto

- Python estandar; sin paquetes externos ni base de datos.
- Sin interfaz grafica; la entrega es un modulo reutilizable.
- Entradas invalidas producen ValueError sin alterar la lista.
- Fechas deterministas: nunca usar la fecha actual del sistema.
- No implementar nada sin criterio de aceptacion verificable.
- Toda modificacion exige actualizar la spec y las pruebas.
